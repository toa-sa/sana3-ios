# سنع · Sana3

**نظّف، افحص، وعدّل صورك.** تطبيق آيفون وآيباد يشيل البيانات المخفية من الصور بنفس الجودة والمقاس بالضبط، ويفحصها من أي محتوى مدسوس، وفيه أدوات تعديل. كل شي يصير على الجهاز، بدون إنترنت.

الإصدار الحالي: **1.3** · يشتغل من **iOS 15** وأحدث (آيفون وآيباد)

## المميزات

**التنظيف** (بدون إعادة ضغط، والبكسلات ما تتغير)
- يشيل الموقع (GPS)، وبيانات الجهاز والعدسة، والتاريخ والبرنامج (EXIF).
- يشيل وسوم الذكاء الاصطناعي و Content Credentials (C2PA / XMP / IPTC)، والـ prompts، والتعليقات، والصور المصغّرة.
- يحافظ على اتجاه الصورة وملف ألوان العرض (Display P3) وبيانات HDR.
- الصيغ: JPG, PNG, WebP, HEIC, TIFF, SVG

**الفحص الأمني**
- يكتشف الملفات الملصوقة (ZIP/EXE/ELF) والأكواد المخفية (PHP، سكربتات، PowerShell) ويشيلها، وينبّهك.
- يرفض الملفات المزوّرة، والامتداد الكذاب، وقنابل الأبعاد والضغط.
- SVG: يشيل السكربتات والروابط الخارجية والـ XXE.

**أدوات التعديل**
- **الخلفية:** شفافة، أو مموّهة، أو لون. خلفية سادة بحواف ناعمة، وفصل الأشخاص والعناصر بذكاء أبل (Vision).
- **المقاس:** مقاسات جاهزة (بوست، ستوري، يوتيوب، X…) أو مخصص، مع قص ذكي وتكبير وسحب.
- **الصيغة:** JPG / PNG / HEIC / SVG للشعارات، مع تحكم في الجودة وتقدير للحجم.
- تراجع خطوة بخطوة، ومقارنة قبل/بعد، وحفظ في الصور، ومشاركة.

**طرق الاستخدام**
- من الصور أو الملفات، أو لصق، أو سحب وإفلات.
- من قائمة المشاركة في أي تطبيق (Share Extension).
- اختصار Siri «نظّف هذي الصورة» (iOS 18 وأحدث).

## البناء

المتطلبات: Xcode و Homebrew (السكربت يثبّت XcodeGen تلقائياً).

```bash
bash build-ipa.command
```

يطلّع ملفين في `dist/`:
- **`Sana3.ipa`**: غير موقّع. كل مستخدم يوقّعه بنفسه.
- **`Sana3-TrollStore.tipa`**: لترول ستور (iOS 15 لين 17.0، والأجهزة اللي عليها جلبريك)، بدون شهادة.

Bundle IDs: `sa.toa.imagecleaner` و `sa.toa.imagecleaner.share`

## النشر الآمن

انشر دائماً الملفات غير الموقّعة من `dist/`، ولا تنشر نسخة موقّعة بشهادتك الشخصية. البناء يشغّل `check-publish.command` تلقائياً، ويوقف لو لقى في الملف شهادة أو Team ID أو ملف mobileprovision.

## هيكل المشروع

```
App/             التطبيق: الشاشة الرئيسية، عن التطبيق، اختصار Siri
ShareExtension/  إضافة المشاركة
Shared/          المنظّف والفحص، الأدوات، SVG، الواجهة
project.yml      إعدادات المشروع (XcodeGen)
```
